# Phase 1 features

One file owns each feature's behavior, implementation guidance and tests. The
[phase specification](../SPECIFICATION.md) is the index. Requirements are not
approved merely because a numbered file exists.

P1-F01 saves the first detailed draft from the agreed mechanism. P1-F02–P1-F09
save agreed behavior and implementation questions only. Discuss those questions
before replacing pending sections with implementation instructions.
