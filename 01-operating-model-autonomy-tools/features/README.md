# Phase 1 features

One file owns each feature's behavior, implementation guidance and tests. The
[phase specification](../SPECIFICATION.md) is the index. Requirements are not
approved merely because a numbered file exists.

P1-F01 saves its detailed direction draft. P1-F02 saves approved source-selection,
pagination, independent cursor authentication, exact indexed symbol lookup and
two-step analysis retrieval and subject-specific freshness notices, with implementation guidance and test scenarios.
Final interfaces, normalization, ordering, changing-list paging, provisioning and
other open contracts still
need discussion. P1-F03–P1-F09 save behavior agreements and implementation questions
only. Do not fill pending sections with assumed defaults.
